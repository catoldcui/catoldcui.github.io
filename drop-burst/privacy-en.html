This policy explains what information the Game handles, why, and what control you have. The Game has no user accounts, no cloud save, and no advertising of any kind.

2. What information we handle

2.1 Data kept on your device (not sent to us)

  • Save data: progress, unlocks, collection, records, settings (volume, language, haptics, reduce motion, the "Usage Analytics" switch, etc.), identifiers of purchased items, and data for resuming an unfinished run. It is stored in the app's local storage, managed by the system.
  • Random install identifier: a randomly generated string created the first time the Game needs it and stored in the local save, used to group events from the same device in usage statistics (Google Analytics 4 calls it the client_id). It contains no name, email or device serial number, but it is a persistent identifier and is legally "pseudonymous" rather than fully anonymous data, so we disclose it together with the statistics in 2.3.
  • Local event log: only development / debug builds write an event log on the device; the release version you install from the App Store does not write this log, and on launch it removes any leftover log from older versions.
  • Daily reminder (if enabled): if the reminder feature is enabled and you turn it on, the Game asks for notification permission and schedules local notifications on your device at the time you choose. No push server is involved.

2.2 Features you choose to use

  • Sharing: when you tap share, the Game builds text (which may include a challenge link and seed code) and a result image and hands them to the iOS share sheet. Where they go is your choice in the system sheet; our servers do not receive them.
  • Challenge links: the Game can open challenges through a custom link (such as yidi://). The link carries a game seed that recreates the same run and no personal information.
  • Feedback email: tapping "Feedback" opens your mail app with the game name, version and OS type (e.g. iOS) prefilled. Whether and what to send is up to you. We receive the content of the email and your email address.
  • Rating: the Game may ask iOS to show its rating prompt. We are not told whether you rated or what you wrote.
  • External links: tapping a link in Settings (such as the privacy policy web page) opens it in the system browser; that website then handles information under its own policy.

2.3 Usage statistics (Google Analytics 4; off by default in Europe, on by default elsewhere, can be changed at any time)

The Game records and uploads usage events to understand level difficulty, whether features are used, and whether the purchase flow works, so we can improve it. Events are received and processed by Google (Google Analytics 4). Events include (per what the code actually logs):

  • Launch and sessions: session start (with OS type, e.g. iOS), moving to background (with current screen).
  • Gameplay: run start / resume / abandon / end, mode, stage name, depth, diver, score and target, stars, taps used, best chain, weapons used and their levels, relics, reward and shop choices, buying and selling, collection and unlocks, opening and closing tutorial and help pages.
  • Challenges and sharing: starting the "Daily Sea" or a challenge (including the game seed code), tapping share and the share-sheet result (shared / cancelled), copying a seed code, opening a challenge link (link scheme type, and the error type when a link is invalid), requesting the rating prompt.
  • Settings: language change, setting changes (setting name and new value), save reset, opening Settings, tapping an external link in Settings (the link address).
  • Purchases: paywall shown and dismissed (source and reason), tapping buy, the product identifier (full), whether purchase / restore succeeded and how many items were restored; no payment method, Apple ID or billing details, which we cannot receive anyway.
  • Reminders (if enabled): permission result, scheduled / cancelled (reminder ID and hour).

Each event carries a timestamp, a session ID and the random install identifier above. Events do not contain your name, email, phone number, precise location, contacts or photos, and no advertising identifier (IDFA). Apart from the OS type, the Game does not deliberately put device model or OS version into events.

How it is sent and what Google sees: events are sent over HTTPS to Google's google-analytics.com. The network request itself lets Google receive your IP address, from which Google infers an approximate region (per Google, GA4 does not log or store full IP addresses). We do not enable Google signals, ads personalization or data sharing with advertising products. While offline, events wait in a local queue (at most 500; the oldest are dropped when full) and are sent later; events still unsent after about 3 days are dropped because GA4 does not accept events that old.

How to turn it off: switch off "Usage Analytics" in Settings. After that the Game stops collecting and uploading statistics events, queued events not yet sent are cleared, and the local log of debug builds is deleted. Upload is controlled by this switch only (there are no ads, so there is no ad-consent flow). Turning the switch off does not erase historical data already uploaded to Google, and does not delete the random install identifier on your device (see Section 5). If you turn it back on, the same identifier is used again.

Default setting: if your device region is an EU member state (including its outermost regions and Åland), Iceland, Liechtenstein, Norway, the United Kingdom or Switzerland, or if the Game cannot determine your region, "Usage Analytics" is off by default and nothing is collected or uploaded unless you turn it on in Settings; in other regions it is on by default. At launch, no statistics event is recorded or uploaded before the switch's state is settled; when the switch is off by default, launch events are simply discarded. Once you have turned the switch on or off yourself, the Game always follows your choice and no longer changes it by region. The region is currently determined from the device's language and region settings.

2.4 Purchases

In-app purchases are handled by Apple's StoreKit and the App Store. The Game has a single one-time purchase, the "Full Version" (a non-consumable item, product identifier full); it is not a subscription and does not renew. We do not receive or store your payment card details, Apple ID or billing address. The Game only records on the device which product you bought, and checks entitlements with Apple through StoreKit (including restoring purchases and revocation after a refund). If a purchase needs a parent's approval through Apple's "Ask to Buy", that approval happens entirely on Apple's side and we receive no information about the parent or child.

3. Why we handle this information

  • To provide the Game: save progress, restore purchases, challenges and sharing.
  • To improve the Game: tune difficulty, fix problems and check that the purchase flow works, based on usage statistics.
  • To reply to your feedback, comply with legal obligations and protect the Game from abuse.

(Legal bases where GDPR applies: performance of our contract with you; for usage statistics, our legitimate interest in improving the product, which you can object to at any time with the switch in Settings; for feedback emails, your own initiative in contacting us.)

4. Who we share it with

  • Google (Google Analytics 4 usage statistics): see 2.3. Google processes the statistics as our service provider and also handles the information carried by the network request itself under its own privacy policy (https://policies.google.com/privacy).
  • Apple (App Store, StoreKit, system share sheet, rating): handled under Apple's own policies.
  • The Game contains no ads and provides no data to any ad network.
  • We do not sell your personal information, we do not provide data to data brokers in exchange for money, and we do not "share" personal information for cross-context behavioral advertising.
  • Where legally required (for example valid legal process), we may disclose necessary information.

5. Retention and deletion

  • On-device data: kept until you delete it. "Reset save" in Settings clears pearls, unlocks, collection, records and any unfinished run, and keeps settings, purchases and the random install identifier. Uninstalling the Game deletes all on-device data, including the random install identifier.
  • Statistics: kept on Google's side for the retention period we set in the GA4 console: 2 months. Google deletes them automatically afterwards.
  • Deletion per person is generally not possible: statistics events are tied only to a random install identifier. We have no account, email or similar data to identify you, and the identifier is not currently shown to you, so we usually cannot look up and delete "a particular person's" statistics. Reinstalling generates a new identifier, and the old one is no longer linked to your device.
  • Feedback emails: we keep correspondence for a reasonable time after your issue is handled; you may ask us to delete it.

  • Manage notification permission in iOS Settings. The Game does not track you and does not read the advertising identifier (IDFA).
  • Depending on where you live (for example EU / UK GDPR, California CCPA / CPRA), you may have the right to access, correct, delete, restrict or object to processing of your personal information, data portability, withdrawal of consent, and to lodge a complaint with a supervisory authority. We do not sell or "share" (in the CCPA sense of cross-context behavioral advertising) personal information.
  • To exercise rights, contact: catoldinc26@gmail.com. We will reply within the time the law requires. As noted, because the data is tied only to a random identifier we may be unable to verify and locate your data.

7. Children's privacy

The Game is not designed for children under 13 (or, where the age of digital consent where you live is higher than 13, for example 16 in some EU countries, under that age), and it is not in the App Store "Kids" category. We do not knowingly collect personal information from such children.

To be clear about the facts: the Game has no accounts and neither asks for nor verifies age; the App Store age rating (4+) reflects content only and does not mean the Game is directed at children. "Usage Analytics" is on by default outside Europe, so if a child uses the Game, the usage events and random install identifier described in 2.3 are collected in the same way. A parent or guardian can switch off "Usage Analytics" in the Game's settings, or uninstall the Game to remove the identifier on the device. If you believe a child under 13 is using the Game and want our help, contact catoldinc26@gmail.com and we will do our best; because statistics cannot be traced to an individual, what we can mainly do is guide you to switch statistics off and explain the retention period, after which Google deletes the data automatically.

Contact for parents: catoldinc26@gmail.com.
